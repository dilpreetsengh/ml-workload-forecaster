# Research and attribution

This project is an independent implementation. It does not copy source code from the projects below.

The architecture was informed by publicly available documentation and research from:

- NeuSight — GPU performance prediction for deep-learning training and inference.
- GPUMemNet — GPU memory-estimation datasets and workload monitoring methodology.
- DeepView.Predict — runtime-based prediction for neural-network training.
- PipeWeave — analytical plus learned performance prediction for transformer workloads.
- llm-analysis — analytical latency, memory, and cost estimation.

Before incorporating any external source code, verify its license, preserve copyright notices, and record the exact files and changes here.
